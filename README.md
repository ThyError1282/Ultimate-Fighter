# The Ultimate Fighter by errorscryption
Welcome to the github repository!
This game was created for hackclub macondo, and it features tons of platform fighter features.
Features:
  Various attacks
  Knockback
  Hitstuns
  Gravity
  And much more!

# Reason for creation
I got inspired by my friends who all were playing 2d platform fighters, so I wanted to surprise them with
my own platform fighter. With regards to the game itself, I spent some time developing the initial idea with
the workflow and scene trees. Hope you guys love the game concept and idea, and I could furthermore expand on it!

# How to run game
If you just want to run a web version of the game, you may use the itch.io link down below and wait for the game to load:
https://error1282.itch.io/ultimate-fighter

However, if you want to run it locally in godot, you must follow several steps:
1. Install the latest godot stable from https://godotengine.org/
2. Download the github repository as a zip by utilizing the dropdown menu from the green code button on https://github.com/ThyError1282/Ultimate-Fighter
3. Open godot stable, press the import button near the top left, and navigate to your downloads where the zip file is, then open the file.
4. You now need to instance globals and inputs, the keys for input can be changed, but the global script name must be Globals, such that it can be
   referenced in all other scripts. For your reference there will be screenshots shown below:
